## 📖 About

xplorer2 is a file management application for Windows developed by ZabKat. It presents two folder panes side by side so you can copy, move and compare files without opening a second window, and it layers on tabs, bookmarks, a synchronised folder tree, mass rename rules, and a search tool that scans names and content. ## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Installer window closes immediately | Reboot, then run the setup file again from a local folder rather than a network path. |
| App opens but panes look empty | Use **View > Refresh** or point the active tab at a drive that is currently connected. |
| Slow listing on network shares | Turn off thumbnail previews for remote folders in the options dialog. |
| Search returns nothing for known files | Check that the search scope is set to the correct root folder and that hidden items are included. |
| Context menu entries missing | Re-run setup and keep the shell integration option enabled during installation. |
| Settings reset after an update | Export your layout to a file before updating, then import it again afterwards. |
